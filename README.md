## Ishga tushirish

1. ZIP faylni to‘liq oching (Extract all / Извлечь всё).
2. `sapfir-stilist` papkasiga kiring.
3. `index.html` faylini brauzerda oching.

Hech qanday paket o‘rnatish yoki build talab qilinmaydi. VS Code ishlatsangiz, `sapfir-stilist` papkasini ochib, `index.html`ni Live Server orqali ham ishga tushirishingiz mumkin.

Rasm va shriftlar lokal. Papka tuzilishini saqlang: faqat HTML faylini alohida ko‘chirsangiz, dizayn va rasm yuklanmaydi. Saytni hostingga joylashda `index.html` va `assets` papkasini birga yuklang.
